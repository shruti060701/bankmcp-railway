## Composer description field (paste this in)

Your AI reads your bank: read-only, self-hosted, no third party ever holds your data.

## Longer version (for context)

A self-hosted, read-only MCP server that connects Claude, ChatGPT, Cursor, or any MCP client to your own bank accounts via Enable Banking's PSD2 open-banking API. No payments, no third party holding your data, single user. This template deploys the official image with the exact same configuration the author's own `railway.json` recommends.

## Why this description
Checked the marketplace first: only two competing listings exist for this template (`bankmcp`, `bankmcptm`), and both use Railway's generic, un-customized "Deploy and Host X on Railway" placeholder — nobody has written an actual description. With no proven framing to reuse or compete against, borrowed from the project's own README tagline ("Your AI now reads your bank... read-only, self-hosted, one user") rather than inventing new copy, since it's already well-written and accurately sets expectations for sensitive financial data.
